# Titanic Dataset – Exploratory Data Analysis

## 📌 Task 5: Exploratory Data Analysis (EDA)

This project focuses on exploring the Titanic dataset using statistical analysis and data visualization techniques.

## 🎯 Objective

To extract useful insights from the Titanic dataset by identifying patterns, relationships, trends, and anomalies using Python.

## 🛠️ Tools & Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab
- GitHub

## 📊 Dataset

The Titanic dataset contains information about 891 passengers with 15 different columns.

The analysis includes passenger details such as:

- Age
- Gender
- Passenger Class
- Fare
- Survival
- Number of Siblings/Spouses
- Number of Parents/Children
- Embarkation Port

## 🔍 Analysis Performed

The following exploratory data analysis techniques were used:

- Dataset information using `df.info()`
- Statistical summary using `df.describe()`
- Missing value analysis
- Survival distribution using `value_counts()`
- Histograms
- Boxplots
- Countplots
- Scatterplots
- Correlation heatmap
- Pairplot

## 📈 Key Findings

- 342 passengers survived, while 549 passengers did not survive.
- Female passengers had better survival outcomes than male passengers.
- First-class passengers had better survival outcomes than third-class passengers.
- Most passengers were approximately 20–40 years old.
- Most passengers paid relatively low fares, with some high-fare outliers.
- Most passengers embarked from Southampton.
- The visualizations helped identify relationships and patterns between passenger characteristics and survival.

## 📁 Project Files

- `Task5_Titanic_EDA.ipynb` – Jupyter/Google Colab notebook containing the complete analysis.
- `Task5_Titanic_EDA_Report.pdf` – PDF report containing the analysis, visualizations, observations, and findings.

## ✅ Conclusion

Exploratory Data Analysis helped identify important patterns, relationships, distributions, and anomalies in the Titanic dataset. The analysis provides a better understanding of the factors associated with passenger survival.
